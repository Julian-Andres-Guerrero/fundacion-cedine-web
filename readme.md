# Fundación CEDINE - Web Oficial

Rediseño moderno, responsivo y bilingüe (ES/EN) del sitio web institucional de **Fundación CEDINE** (Bogotá, Colombia), desarrollado con enfoque en alto rendimiento, accesibilidad y experiencia de usuario con efecto parallax.

## Stack Tecnológico
- **Frontend:** HTML5 Semántico, Tailwind CSS, CSS3 (Parallax & Glassmorphism), JavaScript Vanilla (ES6+).
- **Internacionalización:** Sistema dinámico ligero (`i18n.js`) sin recarga de página.
- **Infraestructura & CI/CD:** Despliegue continuo en Cloudflare Pages con SSL automático y optimización en el borde (Edge).

## Características Principales
- Diseño *Mobile-First* con efecto parallax multicapa compatible con iOS y Android.
- Contadores de impacto animados mediante `IntersectionObserver`.
- Optimización de activos multimedia (`.webp` y video comprimido) para carga instantánea.
